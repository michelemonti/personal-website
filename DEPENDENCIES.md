# External dependencies

The website has two external runtime dependencies:

- [Three.js 0.154.0](https://threejs.org/) — loaded from jsDelivr on the home
  and “work with me” pages for WebGL rendering.
- [Google Fonts — Exo](https://fonts.google.com/specimen/Exo) — loaded from
  Google Fonts on every public page for the site typeface, with a system-ui
  fallback stack in CSS.

Everything else is local, hand-written HTML, CSS and JavaScript. The site
includes no framework, UI library, analytics SDK, package manager or build step.
